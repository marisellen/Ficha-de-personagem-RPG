# Ficha de personagem para RPG
Repositório do trabalho A3 da disciplina Programação de Soluções Computacionais.

## Objetivo do Projeto
- Criar um sistema para gerenciar fichas de personagem de RPG.
- Permitir cadastro, armazenamento e consulta de personagens em um banco de dados.
- Praticar uso de persistência, lógica de negócio e interface.

## Estrutura do Projeto
```
├── database/              # scripts ou arquivos relacionados ao DB  
├── src/                   # código-fonte Java  
│   └── …  
├── .gitignore  
├── Ficha-de-personagem-RPG.iml  
└── README.md
```

## Funcionalidades
- Criar nova ficha de personagem.
- Persistir personagens no banco de dados.
- Consultar ficha de personagens salvos.
- Editar ou excluir personagens.
